# Fuse 1.10.0 – Hungarian Windows edition 1 (v1.10.0-hu.1)

The first release of this fork of Fuse 1.10.0, the ZX Spectrum emulator,
for Windows with its native Windows interface, in Hungarian or English.

## Highlights

- **Hungarian or English user interface** – every menu, dialog and message;
  *Options > General > Language*.
- **Typing with any Windows keyboard layout** – what you type appears on the
  Spectrum (a Hungarian keyboard works as expected); left Alt + number keys
  give Caps Shift + number (EDIT, cursors, DELETE).
- **BASIC programs as text** – *File > Load BASIC text...* and *Save BASIC as
  text...*, including BASin `.bas` files.
- **AY music player with a playlist** – plays `.ay` music files; measures the
  real length of the songs, level meters, channel muting, volume and stereo
  mode while playing, repeat of a song or the whole list; the program that
  was running comes back when the player is closed.
- **Integer-scaled full screen** (F11), **resume last session**, a **keyboard
  picture** that stays above Fuse, windows that open where they were.
- **Sound fixes**: no repeated or stuck sounds, no clicks with DirectSound;
  new **BAC** stereo mode.

The full list of changes is in
[CHANGELOG-fork.md](https://github.com/Viktor318/fuse/blob/hungarian-windows/CHANGELOG-fork.md).

## Installation

1. Download `Fuse-1.10.0-hu.1-windows.zip` below.
2. Unpack it into a folder of your choice.
3. Start `fuse.exe`. Nothing has to be installed.

## Good to know

- Settings and the other files Fuse keeps are in **`%APPDATA%\Fuse`** (type it
  into the address bar of Explorer). Files left in your user folder by earlier
  builds are moved there at the first start.
- The settings (`fuse.cfg`) are saved with *Options > Save*, or at exit when
  *Options > General > Auto-save settings* is on. The places of the windows,
  the AY playlist and the measured song lengths are kept in any case.
- The AY playlist is saved as `.m3u` with `path::AY,song` lines (as the NEZplug
  player does); players that don't know this notation won't find the files.
- After changing the language, windows that are already open show the new
  language when opened again.
